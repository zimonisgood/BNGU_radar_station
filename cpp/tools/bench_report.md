# C++ Radar MVP Bench Report

Generated by `./build/radar_main configs/config.yaml --bench` on this machine.

## Environment

- Backend: `opencv_dnn` (FP32 ONNX fallback; TensorRT not linked in this build)
- Source: static `images/test_image.jpg`
- OpenCV 4.6.0, no NVIDIA driver in CI sandbox

Single-model `yolo_bench` (car only): ~16 FPS, ~62.6 ms/infer.

## Notes for production camera + TensorRT

1. Build with `-DRADAR_WITH_TENSORRT=ON` and matching TensorRT runtime for `models/*.engine`.
2. Set `infer_backend: tensorrt` and `camera_mode: hik` in `configs/config.yaml`.
3. Expect significantly higher E2E FPS vs OpenCV DNN FP32 path above.
4. Original `car.onnx` / `armor.onnx` are FP16; OpenCV DNN needs `*_fp32.onnx` (generated by converting initializers). Prefer TensorRT engines on GPU hosts.
